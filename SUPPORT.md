# Support

Support for the projects under this account is community-driven.

## Where to ask

| Topic | Where |
| --- | --- |
| Bug in a specific repository | Open an issue in that repository |
| Feature proposal | Open an issue, or a discussion if the repository has Discussions enabled |
| Security vulnerability | **Do not** open an issue — see [SECURITY.md](SECURITY.md) |
| Usage question | Discussions on the repository, or the project's documentation |

## What to include

A report that includes the following is usually answered on the first reply:

- what you were doing
- what you expected to happen
- what happened instead, with the full error output
- the version or commit you are running
- the operating system and, for desktop apps, the architecture
